# Selected direction: Hello again / Margin notes

The user selected the [Hello again mood board](hello-again.png), then **G / Margin notes** after three rounds of Home prototypes. The approved combination keeps the coral header and continuous list, adds compact controls and metadata, and uses a cobalt notebook margin with expressive first names.

[Selected G study](selected-g.png) · [Implementation and validation](../../docs/redesign-brief.md)

The mood board is an exploratory visual reference, not the source of logo artwork or product copy. The exact existing logo and all existing view functions are preserved.

The complete exploration, including all nine runnable variants, rejected boards, generation prompts, and the selection verdict, is archived on local branch `prototype/hello-again-exploration` at `aa8c1f7`. Check out that branch separately and run `npm ci` followed by `npm run prototype` to revisit the studies. Variant keys A–I select the experiments; each group of three cycles independently.
